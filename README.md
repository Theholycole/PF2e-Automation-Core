# PF2e Resolution Core (planning)

The future `pf2e-resolution-core` module: the shared plan model, the pure resolver, the plug-in registry and the Foundry apply layer. It will serve PF2e Automatic Spell Resolution, PF2e Automatic Ability Resolution and the PF2e Combat Simulator.

**Status (2026-10-08): design only.** There is no `module.json` and no code. Building it is milestone 2. It starts when the spell module's cleanup is finished and the user picks a date.
